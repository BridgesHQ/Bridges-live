CITY / NEIGHBORHOOD PHOTOS
==========================
Right now every page uses a curated luxury stock photo that loads from the web.
To use YOUR OWN photos instead, drop a file here named exactly:

  tampa.jpg   parrish.jpg   sarasota.jpg   riverview.jpg
  apollo-beach.jpg   bradenton.jpg   wesley-chapel.jpg
  new-construction.jpg   apartment-locating.jpg   relocation.jpg   sell.jpg

Recommended: ~1600px wide, landscape. The page automatically prefers your
local file; if it's missing it uses the stock photo; if that fails it shows
a clean branded plate. You never get a broken image.
