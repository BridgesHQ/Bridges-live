═══════════════════════════════════════════════════════════
COMPONENTS THE DEVELOPER MUST BUILD
═══════════════════════════════════════════════════════════
1. AGENT ONBOARDING
   - Application form (built: /become-a-streamer)
   - Connect social accounts (OAuth: YouTube, Meta)
   - Connect Stripe (agent payout account)

2. LICENSE VERIFICATION
   - Auto-check license # vs FL DBPR / TX TREC databases
   - Store license status + expiry per agent

3. BROKER APPROVAL
   - Admin queue (built: /admin > streamer approvals)
   - Manual approve/reject + KYC (Stripe Identity/Persona)
   - Grant streaming permission on approval

4. PROPERTY AUTHORIZATION
   - Agent attaches a property (from MLS/IDX or manual)
   - Broker/system confirms agent is authorized to show it
   - Compliance log entry

5. MULTI-AGENT PERMISSIONS (the 5,000-agent goal)
   - Role model: viewer / agent / broker-admin
   - Each agent = own stream channel (Amazon IVS stage)
   - Supabase Row-Level Security enforces who sees/does what

6. STREAMING CREDENTIALS
   - Amazon IVS: create a channel/stage per approved agent
   - Give each agent a stream key
   - Bridges Live grid aggregates all active stages

7. SOCIAL INTEGRATIONS
   - Simulcast via Restream OR direct YouTube/Meta Live APIs
   - Embed live + pull comments where APIs allow

8. LEAD ROUTING
   - Viewer "raises hand"/Reserve → lead created (built → Supabase)
   - Route to the streaming agent + notify (SMS/email)
   - Push to CRM

9. CRM
   - Sync leads → HubSpot; track stage lead→tour→contract→close

10. ANALYTICS
    - PostHog events: watch, reserve, lead, appointment, close
    - Per-agent leaderboard + per-stream conversion

11. REVENUE ATTRIBUTION
    - Tie each closed deal back to the stream/agent/lead
    - Commission-split calc (KuaiCommission-style)

12. COMPLIANCE / AUDIT LOGS
    - Log authorizations, approvals, deposits, disclosures
    - Written buyer-agreement capture (post-NAR-settlement)
    - Earnest money → broker trust/title escrow (NOT Stripe)

═══════════════════════════════════════════════════════════
IMPORTANT LEGAL (build these in)
═══════════════════════════════════════════════════════════
- "Reserve" = express interest + refundable hold via Stripe.
  It is NOT a property reservation/contract. Copy must say so.
- Earnest money must go to broker trust account or licensed
  title/escrow — never held in Stripe.
- Written buyer agreement with specific compensation BEFORE showing.
- Referral compensation only between licensed agents/brokers (RESPA).
